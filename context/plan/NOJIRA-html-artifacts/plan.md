# The three HTML artifacts, and the measurement that reads them

> Derived from [A-NOJIRA-pipeline-staging](../../analyzes/NOJIRA-pipeline-staging/analysis.md).
> Starts when [P-NOJIRA-html-contract](../NOJIRA-html-contract/plan.md) has an agreed contract —
> **the whole plan, not one of its tasks.**

## Goal

Produce what a developer receives — the design HTML, and an overlay that marks per element what
matched and what did not — plus the first fidelity figure computed over all of it.

Scope is decided before this plan starts: `P-NOJIRA-corpus-census` ends with an explicit
**full-scope or narrowed** recommendation, and this plan honours it rather than rediscovering it
at task 02.

## Approach

Everything is generated by script from the agreed format. A script has no judgement, so two runs
produce identical bytes — the design system team's repeatability goal satisfied by construction
and checkable as a checksum rather than argued.

**Fidelity is computed from the format, never from the raster.** The build's measured geometry
against Figma's declared geometry, colours against resolved variables, typography against token
values. The reference image is kept for human review and for build-against-build regression.
The geometry comparator itself arrives from the census plan, already tested against a fixture.

**Raw captures stay raw.** The adapter reads them and never rewrites them, so it can itself be
rewritten when it turns out wrong — which, over an undocumented format, it will be.

## Scope

**In:** adapter, closure check, the three generators, determinism proof, fidelity, the six
computable checks, fixture tests.

**Out:** the contract — `P-NOJIRA-html-contract`; anything that calls Figma —
`P-NOJIRA-ingestion-hardening`; framework code generation, which is a script the developer runs
in their own application.

## Work breakdown

- `T-NOJIRA-html-artifacts-01` — Adapter from captures into the format, reporting gaps rather
  than hiding them. **Four provenance classes, four recovery paths** — the census names which
  runs are in which class, so the branches are designed rather than discovered.
- `T-NOJIRA-html-artifacts-02` — Retrofit over every run the census admitted
- `T-NOJIRA-html-artifacts-03` — The closure check: every visited node resolved, captured,
  descended, hidden or excluded, frontier empty
- `T-NOJIRA-html-artifacts-04` — Generator 1, the design HTML
- `T-NOJIRA-html-artifacts-05` — Determinism proof: generate twice, compare checksums.
  **Already true on one run** — two passes of `a3` give identical sha1 — so this is hours
- `T-NOJIRA-html-artifacts-06` — Fidelity from the format, published with its N
- `T-NOJIRA-html-artifacts-07` — The six computable checks `A-NOJIRA-figma-to-code` F5 calls the
  governing principle of the effort, and which until now appeared in no plan
- `T-NOJIRA-html-artifacts-08` — Generator 2, the overlay
- `T-NOJIRA-html-artifacts-09` — Fixture tests for every generator, so none needs Figma

**The progress view is deliberately absent** — a third generator with no named consumer.

## Risks & dependencies

**The overlay's inputs may not exist.** It needs per-decision data — node, source value, emitted
value, basis, delta — and the nineteen runs hold open questions in prose. The overlay over
historical runs will be mostly "unknown", which is an honest result and not the demo anyone
expects. The emitter that fixes this is a pipeline change and belongs to whichever plan owns
`data-figma-node`, currently none.

**The comparison population may be small.** The census settles it. If N stays near four, this
plan's fidelity task publishes four numbers and says so, rather than averaging its way to a
fifth.

**One dependency, and it is on a finished plan.** Nothing here waits on an individual task
elsewhere.

## Acceptance

- The adapter runs over every census-admitted run and the counts sum: adapted plus named-unusable
  equals the census population.
- The closure check agrees with the reconstruction probe on at least nine of the eleven runs
  known to fail it.
- Generating twice produces identical checksums for every adapted run.
- Every fidelity figure states its **N** and the comparator version. A figure without N is not
  published.
- Every generator has tests that run on fixtures with no network access.
