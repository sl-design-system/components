# Grid Selection

This section shows selection features in the Angular Grid wrapper.

Use these examples to select one or multiple rows.

## Basic

Add a selection column and enable multiple row selection.

### Template

```html
<sl-grid [items]="students" selects="multiple" [noSkipLinks]="true">
  <sl-grid-selection-column></sl-grid-selection-column>
  <sl-grid-column path="id" header="Nr."></sl-grid-column>
  <sl-grid-column path="fullName" header="Student"></sl-grid-column>
  <sl-grid-column path="email" header="Email"></sl-grid-column>
</sl-grid>
```

### Props

```typescript
{
  students: Student[];
}
```
